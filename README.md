# Boot Sector (web build)

A retro-computer pinball table made in Godot 4, exported for the browser.
Play it at https://bootsector.johnshawler.com

Controls: Enter starts a game. Left / right arrows (or Z and /, or the Shift keys) are the
flippers. Hold and release Space to plunge. Up arrow nudges. C changes camera, M mutes,
P pauses, F goes fullscreen.

This repository holds only the exported build that the site serves.
